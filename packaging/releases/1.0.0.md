Papo 1.0.0 brings the current GTK frontend to modern Linux desktops.

### Changes

- Text chat in voice channels, with separate chat and call permissions. Open the chat icon beside a voice channel without joining audio, and switch chats while staying in a call.
- Better media caching and bounded history retention, with smoother channel switching and scrolling.
- MOV/QuickTime playback, animated media fixes, and improved thumbnail geometry and embed sizing.
- Updated backend support, including webhook sender identities and shared avatars in search and notifications.
- Fixes for search filters, navigation to older messages, reply emoji sizing and GTK layout warnings.

### Downloads

Both packages are **Linux x86_64** builds of this release:

- **AppImage:** `Papo-1.0.0-x86_64.AppImage`. Make it executable and launch it. Built with Fedora 44; requires **glibc 2.43 or newer**. Native desktop font settings and scaling are preserved. See the attached AppImage README.
- **Flatpak:** `Papo-1.0.0-x86_64.flatpak`. Install with `flatpak install --user ./Papo-1.0.0-x86_64.flatpak`, then run `flatpak run br.com.papo.gtk`. Uses the GNOME 50 runtime, downloaded from Flathub when needed. This is a standalone GitHub bundle, not a Flathub app listing or an automatic app update repository.

`SHA256SUMS` verifies the downloads. `papo-gtk-1.0.0-source.tar.gz` contains the matching frontend source and build recipes.

### Package checks

The offline checks use synthetic media and no account or physical devices:

```sh
./Papo-1.0.0-x86_64.AppImage --runtime-check
./Papo-1.0.0-x86_64.AppImage --check-media-runtime
flatpak run --command=papo-runtime-check br.com.papo.gtk
```

Voice, camera and screen sharing require working desktop audio services and portals. Actual devices and GPU-specific hardware decoding need testing on the target desktop.
