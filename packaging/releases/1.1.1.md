# Papo 1.1.1

Linux packages are stable. Windows downloads remain **experimental and unsigned**.
macOS remains groundwork, without a downloadable application bundle.

## Changes

- Add smooth mouse-wheel scrolling across notification windows, settings,
  search, pickers and other scrollable dialogs. Preserve touchpad scrolling,
  reduced-motion settings and fractional high-resolution wheel input. Correct
  widget hit detection in decorated windows, including Windows.
- Reduce decoded and compressed media-cache memory budgets while retaining
  recent opening batches and reusing existing images when switching channels.
- Play animated WebP and APNG media alongside GIFs, including FxTwitter
  animation links supported by the backend.
- Render Reddit previews from backend metadata, including available post
  images/video, original-language titles and native post actions.
- Show a screen-sharing indicator and a lightweight local preview of the
  transmitted screen, with bounded frame delivery and independent preview
  controls.
- Allow notification preferences for every channel and add right-click channel
  mute/unmute actions. Remove stale unread indicators after message deletion.
- Render custom emojis in channel headers; fix emoji-picker Escape handling,
  single-result completion spacing, multiline-composer sizing and reply-banner
  alignment. Improve link and emoji hit areas and inline emoji positioning.
- Expand native Windows GUI coverage, including physical wheel-event delivery,
  decorated-window coordinates, notification tabs and image-viewer controls.

## Verification and limitations

`RELEASE-VERIFICATION.json` records the source commit, actual CI outcomes and
checks against the distributed packages. `WINDOWS-CI-RESULTS.json` preserves the
full automated candidate-gate result. These do not establish signed or supported
Windows 11 desktop qualification.

No signing certificate is available, so Windows may show an unknown-publisher
or reputation prompt. Real audio/camera devices, attended screen selection,
mixed-DPI monitors and Windows 11 Home/Pro acceptance remain pending.

The owner-diagnosed Linux GStreamer playback-teardown crash is not claimed fixed.
Any recurrence remains a failed test in the verification report. Reddit media
availability depends on the backend and upstream access; the frontend does not
scrape Reddit or execute remote embed HTML.
