# Chat and call configuration fixes — 2026-11-05

Implemented the six items supplied in `bug_fixes.txt`:

1. Acknowledged read cursors survive stale channel snapshots. Typing and clearing a draft removes the draft indicator without restoring the unread dot.
2. Local audio tests use audio-only enumeration when an explicit device needs it, let finite playback preroll, and release the recording bus before replay. Unrelated input additions no longer interrupt a local default microphone test. Errors retain the worker's actionable message.
3. Pending messages display their text, author, avatar and timestamp immediately. Sending controls appear after 500 ms; errors remain immediate.
4. Native file drops stage local attachments in the current chat. They share attachment limits, permission checks, asynchronous inspection, previews and stale-conversation rejection with existing uploads.
5. Bottom-of-chat events request read acknowledgments immediately. Newer visible cursors queued behind an in-flight acknowledgment continue as soon as it finishes; failure cooldowns remain intact.
6. Scroll restoration preserves the visible message through multiple layout frames after older messages are prepended, including updates arriving during wheel animation.

Regression coverage includes the new `chat-behavior` GTK case, the extended `backend-update` draft/read workflow, read-journal unit tests, and default-routing/preroll/hotplug audio tests.

Validation: 348 Rust tests, 29 Python voice-worker tests, eight focused GTK cases (`chat-behavior`, `backend-update`, `audio-setup`, `outgoing-queue`, `clipboard`, `draft-recovery`, `window-scrolling`, `report10`), translation validation and whitespace checks. Native playback and microphone record/replay also completed through temporary virtual audio devices. Physical microphones and speakers were not used.
