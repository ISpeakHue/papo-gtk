Papo 1.0.2 fixes missing and inconsistent control icons in AppImage and Flatpak builds.

### Changes

- Embed 47 application control icons in the executable, keeping the toolbar, composer, media controls and disconnect button consistent across desktop icon themes.
- Use Papo-specific icon names so a desktop theme unavailable inside the package cannot leave controls with missing-image symbols.
- Replace an unavailable voice-channel chat icon with bundled Adwaita artwork. Symbolic foreground colors continue to follow the active light/dark theme and button state.
- Include icon attribution and license notices in both packages, with automated resource coverage checks.
- Expand code documentation in EN-US and PT-BR.

### Downloads

Both packages are **Linux x86_64** builds of this release:

- **AppImage:** `Papo-1.0.2-x86_64.AppImage`. Make it executable and launch it. Built with Fedora 44; requires **glibc 2.43 or newer**. Native desktop font settings and scaling are preserved. See the attached AppImage README.
- **Flatpak:** `Papo-1.0.2-x86_64.flatpak`. Install with `flatpak install --user ./Papo-1.0.2-x86_64.flatpak`, then run `flatpak run br.com.papo.gtk`. Uses the GNOME 50 runtime, downloaded from Flathub when needed. This is a standalone GitHub bundle, not a Flathub app listing or an automatic app update repository.

`SHA256SUMS` verifies the downloads. `papo-gtk-1.0.2-source.tar.gz` contains the matching frontend source and build recipes.

### Validation

The icon fix passed 282 regular Rust tests, seven Python checks and the focused GTK icon case. All 47 icons were checked in both packaged runtimes with Adwaita, Breeze and an unavailable desktop theme selected, at 1× and 2× scale. The broader GUI-test limitations reproduced on unchanged main are documented in [desktop testing notes](https://github.com/ISpeakHue/papo-gtk/blob/v1.0.2/docs/testing/desktop.md#bundled-control-icons).

Both versioned packages report 1.0.2 and passed runtime, isolated media conversion and private Wayland startup checks. The AppImage also passed font diagnostics.

The offline checks use synthetic media and do not open an account session or capture devices:

```sh
./Papo-1.0.2-x86_64.AppImage --runtime-check
./Papo-1.0.2-x86_64.AppImage --check-media-runtime
flatpak run --command=papo-runtime-check br.com.papo.gtk
```
